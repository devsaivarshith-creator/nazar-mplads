## 🚀 Quickstart (Running Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🔒 Security
No API keys or sensitive credentials are ever stored in source control. Configure your local `.env.local` according to the main [README.md](../README.md#step-3-configure-environment-variables).
